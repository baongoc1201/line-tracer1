How it works

The learner reads short Python programs and types what they print. When an answer is wrong, the tool finds which misconception explains it and chooses the next exercise from that. This is the trial version; the page you used before is unchanged.

In the first trial Feedback is off: the page does not say which answer is wrong, so the follow-ups measure but do not teach.

Type the output

Right: next exercise.

Line by line

Wrong: one question per variable, until the first wrong answer.

Help

Smaller programs, to find where right turns into wrong.

Next exercise

From the mistake (kinds below).

Log

Google Sheet: one row per exercise and per student.

More about the help
  • Each wrong answer is compared with what every misconception would answer there ("fits M3, X19").
  • Help: smaller programs (the right side alone, the numbers alone …) to find where right turns into wrong; this also tells apart misconceptions that give the same answer.
  • One misconception left: suspected. The follow-up tests it in another kind of line; the same mistake there: confirmed.
  • Check: only when two or more are still left, the same line with new numbers, to tell them apart.
  • The log says, for every answer, what it fits, and under the result, why (what ruled each misconception out).

Kinds of exercises

  • 8 main exercises, the same for everyone, easy to hard.
  • At most 2 follow-ups after a main exercise, only from its mistake. A new mistake in a follow-up is only logged.
  • A misconception tested in 3 exercises gets no more follow-ups.
  • In a follow-up, a mistake already confirmed gets no help and no check.

Not an exercise, and planned after the trial
  • After the help: the tool waits for a line of the same kind in a later exercise, to see whether the learner solves it alone.
  • Not known yet: a question after the first wrong answer is never asked; what it would show is marked "–" in the Summary, not taken as right.
  • Planned, with Feedback on: small practice exercises for a misconception already found (for example x = 4; x = 9; print(x) for M1), and a "Harder" set (a text times a number, decimals).

How the bank exercises are made

1. Templates with blanks

11 templates, 3 to 6 lines, such as {v} = {n1}; {v} = {n2}; print({v}) (Kumar, 2005).

2. Filling the blanks

Names from 10 neutral words (total, count, score, price, age, size, level, points, steps, speed), so learners cannot guess from the name. Numbers 1 to 9, all different, so the arithmetic is easy.

3. Two checks

Kept only if each target misconception makes the output wrong, and no other misconception gives the same wrong output. Otherwise drawn again.

4. A fixed bank

5 exercises per template, 55 in all, in a file that can be read first. Another template comes first; a learner meets each exercise at most once.
