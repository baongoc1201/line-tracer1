Misconceptions the tool tries to catch

Play a student who holds one of these

M1 A variable holds several values

Each assignment adds a value; print shows all of them. In a calculation the newest value is used.

x = 4
x = 9      # x is "4 9"

M3 A variable keeps its first value

Once a variable has a value, later assignments to it are ignored.

x = 4
x = 9      # x is still 4

M4 A variable stores the expression as text

The right-hand side is not computed; the variable holds its text. A plain number is stored as a number.

a = 2
b = a * 3  # b is "a*3"

M5 A variable keeps the formula

Like a spreadsheet cell: the variable is recomputed whenever it is used, so it follows later changes. x = x + 1 is computed at once.

x = 1
y = x + 4  # y is 5
x = 6      # now y is 10
Also recorded in the log (watch-list, outside the set)

M2 A new value is added to the old one

Reassigning a whole number adds it to the value already there.

a = 3
a = 10     # a is 13

X19 Assignment copies the wrong way

a = b is read as "copy a into b" when both already have values.

a = 3
b = 5
a = b      # a is 3, b is 3
